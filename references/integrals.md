# Integral Simulations

Use this reference when a request is an integral exercise and the expected output is an exact interactive explanation. The simulation must make the integral graphical first; algebra is support, not the whole animation.

## Contract

Use simulation type `indefinite_integral` for primitives and antiderivatives.

Required math fields:

- `integrand`: source integrand in SymPy-compatible syntax.
- `variable`: integration variable.
- `domain`: regular visual interval for the graph. Avoid singularities and discontinuities.
- `anchor`: base point `x0` used to interpret one primitive as accumulated signed area.
- `method`: selected integration route.
- `substitution`: main substitution when used.
- `rational_integrand`: transformed integrand after substitution when the method produces one.
- `partial_fractions`: partial fraction decomposition when needed.
- `antiderivative_t`: primitive in the substituted variable when used.
- `antiderivative`: final expression in the original variable.

## Method Choice

Pick the smallest exact route:

- Direct simplification when the derivative pattern is immediate.
- `u` substitution when one inner derivative is present.
- Integration by parts when there is a product with a clear differentiating/integrating choice.
- Partial fractions when the integrand is rational or becomes rational.
- Weierstrass substitution `t = tan(x/2)` when a trigonometric rational expression mixes `sen x`, `cos x`, `tan x`, and direct substitution does not isolate the variable.

For Weierstrass, use:

```text
sen x = 2t / (1 + t^2)
cos x = (1 - t^2) / (1 + t^2)
tan x = 2t / (1 - t^2)
dx = 2 / (1 + t^2) dt
```

## Scene Pattern

Keep each scene to one conceptual action:

1. Draw axes for a regular interval of the integrand.
2. Draw the integrand as a curve `f(x)`.
3. Sweep signed area from `x0` to a moving `x`.
4. Draw the primitive curve generated by that accumulated area.
5. Show the family `F(x)+C` as vertical translations.
6. Introduce the selected algebraic method.
7. Transform the integrand.
8. Decompose or simplify the transformed expression.
9. Integrate the resulting terms.
10. Substitute back to the original variable.
11. Verify by differentiating and tying the derivative back to the original graph.

## Validation

Do not render an integral simulation until the symbolic checks pass:

- original integrand matches the statement;
- substitution identities are internally valid;
- transformed integrand matches the substitution;
- partial fractions match the transformed integrand;
- derivative of the primitive matches the integrand, directly or through the substituted variable.
- selected visual domain avoids singularities of the integrand.

## Rendering

- Use typewriter-style TeX text for formulas until a TeX renderer is added.
- Use smooth timeline transitions and a draggable scrubber.
- Use the Cartesian plot as the main stage for integral exercises.
- Tie algebraic arrows, highlights, and captions to the active graphical transformation.
- Show indefinite integrals as a primitive family: one accumulated-area primitive plus vertical `+C` shifts.
