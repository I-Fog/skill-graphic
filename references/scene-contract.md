# Scene Contract

Each scene represents one conceptual step. Avoid scenes that combine multiple learning goals.

## Required Fields

- `id`: stable hyphen-case identifier.
- `goal`: what the learner should understand.
- `action`: renderer instruction.

## Optional Fields

- `duration_ms`: default animation duration for the scene.
- `caption`: short in-frame explanation.
- `formula`: TeX-like expression shown in the floating formula overlay.
- `targets`: stable ids of features or objects the action should affect.
- `args`: action-specific parameters, such as `point_id`, `interval_id`, or camera/focus values.

Prefer explicit `targets` or `args` whenever an action needs a concrete object. A renderer should not guess which point receives a tangent or which asymptote should be highlighted.

## MVP Actions

- `draw_axes`: reveal the coordinate system.
- `draw_curve`: stroke-draw the function over its domain.
- `highlight_interval`: mark endpoints or bounds.
- `show_rotation_axis`: emphasize the axis that remains fixed.
- `rotate_curve_into_surface`: animate the angle parameter, surface mesh, and camera/viewbox progress together when the concept depends on seeing the generated surface.
- `move_camera`: hold or refine viewpoint after the model has already been generated.
- `show_formula`: reveal a formula tied to the visible object.
- `show_validation`: summarize the checks that passed.

## Integral MVP Actions

- `draw_integrand_graph`: draw the Cartesian graph of the integrand `f(x)`.
- `sweep_signed_area`: move a cursor from `x0` and shade signed area under `f`.
- `draw_primitive_curve`: draw the primitive curve generated by accumulated area.
- `show_primitive_family`: show vertical shifts representing `F(x)+C`.
- `introduce_substitution`: introduce the exact algebraic method after the graph has established meaning.
- `transform_integrand`: convert the integral to the selected transformed form.
- `split_partial_fractions`: decompose the transformed integrand when needed.
- `integrate_terms`: integrate the transformed terms.
- `back_substitute`: return to the original variable.
- `verify_derivative`: tie the derivative of the primitive back to the drawn integrand.

## Function Graph MVP Actions

- `draw_function_graph`: draw the source curve on the validated visual domain.
- `trace_point`: move a point along the curve and update coordinate/slope context.
- `show_tangent`: draw a tangent line computed from the validated derivative.
- `show_extrema`: mark validated maxima or minima.
- `show_inflection`: mark validated concavity changes.
- `show_asymptote`: draw declared and validated asymptotes.
- `show_discontinuity`: mark declared and validated holes or jumps.
- `show_derivative_graph`: draw `f'(x)` after the source curve is established.
- `show_antiderivative_graph`: draw a validated primitive or accumulated curve.
- `compare_function_and_derivative`: connect slope/sign behavior across related curves.

## Surface-Of-Revolution Fixture Rules

- Keep one visual stage for the canonical fixture.
- The surface mesh starts at the drawn curve; the first generated generatrix must not appear offset below the function.
- The view moves toward the upper-right curve endpoint while the surface is generated.
- Axis labels appear only after their axes are fully drawn.
- The timeline control is a scrubber, so every scene must render correctly when time moves backward.
- Generated pages may accept a `?t=0..1` query parameter for direct visual validation of a timeline instant.
